# SoundFont licences

Established 2026-10-09 from web search results (sources not yet archived under `research/`).

- FluidR3_GM is MIT (Frank Wen, copyright 2000-2002 and 2008). Debian's copyright file lists it as MIT. Copyright and licence notices must ship with it.
- GeneralUser GS v2.0 uses a custom permissive licence (S. Christian Collins), classed Permissive by ScanCode. It allows use in software projects and modification. The author states he cannot be 100% sure of the origin of every sample.
- Soundfonts are data, so they do not force a licence on the app code. The app code is GPL-3.0 (see `plan.md`).

Unverified: the GeneralUser GS text came from the ScanCode mirror, not the author's repository. Verify before release.
